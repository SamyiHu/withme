# 回复实验室（reply_lab）

用**公开的真实聊天语料**离线评测回复质量，靠数据改提示词，而不是拍脑袋。

## 安全边界（硬性）

- **不接微信桥、不发任何消息**：只在 `tempfile` 建的临时库里跑 `on_user_message`，
  不 import `wechat_bridge`，不连 hook，不写 `data/agent.db` 和 `data/wechat_users/`。
- 检测到 `AGENT_DB_PATH` 环境变量会直接拒绝运行（防误指线上库）。
- 每条用例一个全新沙盒；关掉主动/反思/感知/表情包，只评"收到一句 -> 回一句"。
- 语料只用**公开数据集**（不采集私聊、不抓个人账号），下载物放 `data/reply_lab/`（gitignore）。

## 语料

| 来源 | 说明 |
|---|---|
| LCCC（CDial-GPT）`toy_data.json` | 微博真实多轮对话，自带 train/valid/test；本仓库用它的 toy 样本做冒烟 |
| 任意 JSONL | `{"context": ["..."], "reply": "..."}`，可接自己收集的公开语料 |

LCCC 全量需自行下载（Google Drive），只放进 `data/reply_lab/`，不入库。

## 用法

```bash
# 冒烟：10 条真实对话，出报告到 reports/reply_lab/
python -m tools.reply_lab.evaluate --n 10

# 跑自己的语料
python -m tools.reply_lab.evaluate --corpus data/reply_lab/my_cases.jsonl --n 30
```

报告指标：平均/中位长度、超 36 字条数、问号率、句末句号率、emoji 率、复读条数、
与人类原话的二元组重合度、平均耗时。**人类原话就是基线**。

## 已验证的迭代记录（2026-10-29，10 条 LCCC 真实对话）

| 版本 | 平均长度 | 中位 | >36 字 | 问号率 |
|---|---|---|---|---|
| 人类原话（基线） | 9.5 | 10.5 | 0 | 10% |
| 改前 | 21.0 | 19.0 | 2 | 50% |
| + `too_long` 打回重写（>30 字压到 15 字） | 16.8 | 16.5 | 0 | 30% |
| + "关心别拿钟点当理由"（禁催睡式关心） | **15.7** | **13.0** | 0 | **10%** |

## 下一步（长线）

1. 扩语料到 500~2000 条（LCCC 全量 / 其他公开聊天集），按场景分层（闲聊/求助/被怼/深夜）。
2. 加 LLM 评审维度（自然度/贴题/情绪匹配/像人），与人类原话做 A/B。
3. 参数搜索：长度上限、问号频率、语气词密度、表情包阈值——每次只动一个变量，用同一批 seed 复跑。
4. 把胜出的规则固化进 `persona.yaml` + `reviewer` 机械兜底，回归测试防退化。
