# ADR-001：成长 = 慢速外环收敛到用户拟合的不动点

状态：已采纳（2026-10-30）
影响范围：`src/growth.py`（新）、`src/main.py` 反思接线、`src/prompt_builder.py`、`db/schema.sql`、控制台

## 背景

原反思层用固定步长改吸引子中心（`trait_shift`，单步 ≤0.05，累计 ≤0.15），
规则列表满了静默丢弃。结果是：

- 短期有变化，长期会停在硬上限，用户感知为“成长没有”；
- “永久性”只能靠不断往提示词里塞规则，撑爆 token，最后又被迫封顶。

用户要的是：聊得越多，越朝某个方向长，看得见，并且跟随记忆永久存在。

## 决策

把“成长”拆成两个时间尺度，**都保持有界**：

| 层 | 时间尺度 | 变量 | 动力学 | 边界 |
|---|---|---|---|---|
| 状态层（现有） | 秒~分钟 | 7 维状态 `x` | 向吸引子中心 `c` 回拉 | 容差内（P1 验收不变） |
| 成长层（本 ADR） | 天~周 | 中心偏移 `p` | 向目标 `P*` 收敛 | 每维包络 `±E` |
| 核心层 | 永不 | 身份/不变量/边界 | 不参与 | 不可漂移 |

成长不是无限累加，而是**收敛到由用户行为拟合出的不动点**：

```
Est_t = f(证据) + w_llm · trait_shift        # 目标估计（每维裁剪到 ±E）
P*_t  = P*_{t-1} + α_t · (Est_t − P*_{t-1}) # 目标本身用 EMA 抗噪
η_t   = η0 · exp(−n_t / κ)，偏离 ≥ δ 时抬到 max(η_t, η_min)  # 会饱和，但保留可塑性
p_t   = clamp(p_{t-1} + clip(η_t · (P*_t − p_{t-1}), ±s_max), ±E)
```

- `n_t`：累计参与成长的用户消息数；`η_t → 0`，所以同一批数据重复喂不会无限移动；
- `P*` 是用户长期行为（回应率、情绪、话题深度、关系亲密度、拒绝率）的统计目标；
- 核心不变量、边界、身份摘要**不参与** `p`，避免“聊成另一个人”或迎合式改写；
- 每维包络 `E` 另受状态取值范围约束：`E_dim ≤ min(hi−base, base−lo)`。

## 为什么这不是“人格无界漂移”

- 状态层的距离/一致性验收完全不受影响：`p` 只是把回拉中心挪到一个新的、有界的点；
- `p` 有硬包络，且步长随证据衰减，长期停在 `P*` 而不是越走越远；
- 需要时可以 `reset` 回角色卡（日志保留为审计）。

## 提示词与成本

- 【长期成长】段只放**收敛后的画像摘要**（≤220 字，稳定前缀，变化慢）；
- 原始成长日志只进 SQLite（`growth_events`），不进提示词；
- 【成长规则】仍保留少量操作习惯（`max_extra_rules`，FIFO），与长期画像分工不同。

## 验收（固定数据集，离线确定性）

1. **收敛**：固定证据重复 N 轮，`|p_{t+1}−p_t|` 单调下降到 `<1e-6`；
2. **饱和**：同一批数据继续喂，`p` 不再移动；
3. **跟随**：证据方向反转后，`P*` 移动，`p` 在新包络内重新收敛；
4. **包络**：任意极端证据下 `p` 不超过 `±E`，且 `base+p` 不超出维度取值范围；
5. **核心不动**：反思/成长不改 `core_invariants`、`boundaries`；
6. **P1 不变**：状态层收敛测试继续通过；
7. **回滚**：`reset` 后 `p=0`、`P*=0`、状态中心回角色卡。

## 参数（`reflection.*`）

| 参数 | 默认 | 含义 |
|---|---|---|
| `growth_envelope` | 0.25 | 每维成长包络（相对角色卡） |
| `growth_eta0` | 0.5 | 初始步长系数 |
| `growth_eta_min` | 0.01 | 长期可塑性下限（目标变化时仍能缓慢跟随） |
| `growth_wake_gap` | 0.02 | 偏离超过该值才启用可塑性下限 |
| `growth_kappa` | 200 | 步长指数衰减尺度（累计消息数） |
| `growth_max_step` | 0.03 | 单次反思最大移动 |
| `growth_alpha` | 0.25 | 目标估计 EMA 学习率 |
